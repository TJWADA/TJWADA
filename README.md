# TJWADA

I build product-shaped software — native iOS and TypeScript web — and care about the parts that usually get skipped: privacy, scoring math, and making a demo runnable without a pile of API keys.

## Featured

### [BetterReminders](https://github.com/TJWADA/BetterReminders)
Voice-powered reminders for iPhone. Press the Action Button, speak, and the app transcribes on-device, then uses OpenAI to summarize and sort into the right list.

Swift · SwiftUI · SwiftData · App Intents · Speech

### [MoFF](https://github.com/TJWADA/MoFF)
Mixture of Finfluencers. Pulls YouTube finance videos, extracts trade calls with an LLM, scores them against SPY, and shows where channels currently agree or disagree.

Next.js · TypeScript · Drizzle · Zod · OpenAI · Alpaca

## Stack

**iOS** — Swift, SwiftUI, SwiftData, App Intents  
**Web** — TypeScript, Next.js, React  
**Data / ML** — SQLite, Zod, OpenAI APIs
